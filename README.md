# E-Commerce Purchase Behavior Analysis

## Project Overview
This project focuses on analyzing e-commerce sales and customer purchasing behavior using SQL and Power BI.

The objective was to explore sales performance, customer trends, product profitability, shipping patterns, and the impact of discounts on business performance through data analysis and visualization.

This project was completed as part of my Junior Data Analyst Internship at HACKTECH.

## Project Objectives
1. Analyze overall sales and profit performance.
2. Identify top-performing products, categories, and regions.
3. Understand customer purchasing patterns.
4. Evaluate the relationship between discounts and profitability.
5. Identify loss-making products and business areas.
6. Analyze shipping modes and delivery trends.
7. Develop an interactive Power BI dashboard to present key findings.

## Tools & Technologies
1. PostgreSQL- Data storage and SQL-based analysis
2. pgAdmin 4- Database management and query execution
3. Microsoft Power BI- Data visualization and dashboard creation
4. SQL- Data exploration, analysis, and business insights.

**Dataset**: 
Global Superstore Dataset by Rony (Kaggle)
- Total Records: 51,290
- Total Columns: 27
- Data Type: E-commerce transactional data  
The dataset contains information about orders, customers, products, sales, profits, discounts, shipping, and geographical regions.

## Project Workflow

1. **Data Preparation**
- Imported the Global Superstore dataset into PostgreSQL.
- Created the project database and orders table.
- Verified the imported records and explored the dataset structure.

2. **SQL Data Analysis**  
Performed exploratory and business-oriented analysis using SQL queries.  
The analysis covered:
- Basic data exploration
- Sales and profit analysis
- Customer analysis
- Product and category performance
- Regional sales analysis
- Loss-making products
- Discount vs. profit analysis
- Shipping cost and delivery analysis

3. **Power BI Dashboard**  
Created an interactive dashboard in Power BI to visualize the analysis and communicate important business trends.    
The dashboard helps explore sales performance, profitability, product categories, customer segments, and regional distribution.

## How to Explore the Project-
**SQL Analysis**-
1. Download the SQL file from this repository.
2. Import the dataset into PostgreSQL.
3. Open pgAdmin 4.
4. Execute the queries to explore the analysis.

**Power BI Dashboard**-

2. Open it using Microsoft Power BI Desktop.
3. Explore the interactive visualizations and filters.
